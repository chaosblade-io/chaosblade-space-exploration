# svc-k8s-graph 系统架构图设计规范

## 基于顶级学术会议（ICSE、FSE、ISSTA、ASE）可视化标准

---

## 1. 宏观设计意图与叙事功能

### 1.1 图表定位

本架构图作为技术报告的**核心可视化元素**，承担以下叙事功能：

| 功能维度 | 具体目标 |
|----------|----------|
| **概念传达** | 展示六阶段风险分析 Pipeline 的设计哲学 |
| **流程阐释** | 呈现数据从输入到实验配置的完整转换路径 |
| **创新突显** | 强调 LLM 集成与 RiskRank 算法的创新点 |
| **复杂度管理** | 在保持信息完整性的同时控制认知负荷 |

### 1.2 图表类型选择

采用**混合型架构图**，融合以下三种可视化范式：

1. **Pipeline 流程图** (左→右)：展示六阶段顺序执行关系
2. **分层架构图** (上→下)：展示系统分层（Controller → Service → Client）
3. **数据流图** (DFD)：展示外部系统交互与数据变换

### 1.3 核心叙事线索

```
输入层 → 数据采集 → 多层分析 → 智能推理 → 配置生成 → 实验执行
   │         │          │          │          │          │
   ▼         ▼          ▼          ▼          ▼          ▼
[K8s/Obs] [Phase1-2] [Phase3] [Phase4-5] [Phase6] [ChaosBlade]
```

## 2. 实体建模与逻辑拓扑

### 2.1 核心实体清单

#### 2.1.1 外部系统实体

| 实体名称 | 类型 | 功能描述 |
|----------|------|----------|
| Kubernetes API | 外部数据源 | 提供集群配置信息（Deployment/StatefulSet/PDB） |
| Coroot/Jaeger | 可观测性平台 | 提供 ServiceMap、Trace 数据 |
| LLM Service | AI 服务 | OpenAI/Anthropic，提供推理能力 |
| ChaosBlade Box | 混沌平台 | 执行故障注入实验 |

#### 2.1.2 Pipeline 阶段实体

| 阶段 | 核心组件 | 输入 | 输出 |
|------|----------|------|------|
| Phase 1 | RiskRuleEngineService | K8s Resources | ServiceRiskProfile |
| Phase 2 | TopologyRiskLLMService | ServiceMap + Phase1 | TopologyRiskResult |
| Phase 3 | RiskRankAlgorithm | Phase1 + Phase2 | RiskRankResult |
| Phase 4 | TraceAnalysisService | Trace Data | TraceAnalysisResult |
| Phase 5 | ComprehensiveAnalysisService | Phase1-4 | ComprehensiveAnalysisResult |
| Phase 6 | ExperimentConfigService | Phase5 | ExperimentConfig |

#### 2.1.3 编排实体

| 实体名称 | 职责 |
|----------|------|
| RiskPipelineOrchestrator | Pipeline 调度与状态管理 |
| PipelineResult | 聚合所有阶段结果 |

### 2.2 逻辑拓扑与数据流

#### 2.2.1 主数据流路径

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           完整数据流路径                                  │
└─────────────────────────────────────────────────────────────────────────┘

[K8s API] ─────────────────────────────┐
                                       ▼
                              ┌─────────────────┐
[Coroot/Jaeger] ─────────────▶│ RiskPipeline    │
                              │ Orchestrator    │
[LLM Service] ◀──────────────▶│                 │
                              └────────┬────────┘
                                       │
        ┌──────────────────────────────┼──────────────────────────────┐
        ▼                              ▼                              ▼
   ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
   │ Phase 1 │───▶│ Phase 2 │───▶│ Phase 3 │───▶│ Phase 4 │───▶│ Phase 5 │
   │ Rules   │    │ Topo+LLM│    │ RiskRank│    │ Trace   │    │ Synth   │
   └─────────┘    └─────────┘    └─────────┘    └─────────┘    └────┬────┘
        │              │              │              │               │
        ▼              ▼              ▼              ▼               ▼
   [Profile]      [TopoRisk]    [Ranking]     [TraceSummary]    [Scenarios]
                                                                     │
                                                                     ▼
                                                              ┌─────────────┐
                                                              │  Phase 6    │
                                                              │ ConfigGen   │
                                                              └──────┬──────┘
                                                                     │
                                                                     ▼
                                                            [ExperimentConfig]
                                                                     │
                                                                     ▼
                                                            [ChaosBlade Box]
```

#### 2.2.2 控制流路径

| 控制流 | 描述 |
|--------|------|
| 顺序执行 | Phase 1 → 2 → 3 → 4 → 5 → 6 |
| 条件分支 | Phase 2/5 LLM 不可用时回退到规则模式 |
| 错误处理 | 各阶段失败后中止 Pipeline 并记录状态 |

## 3. 视觉编码与美学规范

### 3.1 色彩语义系统

采用学术论文推荐的**低饱和度、高区分度**配色方案：

#### 3.1.1 功能性色彩映射

| 功能类别 | 主色 (HEX) | 语义 | 应用对象 |
|----------|------------|------|----------|
| 数据采集 | `#4A90A4` (灰蓝) | 稳定、输入 | K8s API、Coroot、外部系统 |
| 规则分析 | `#5B8C5A` (森绿) | 逻辑、规则 | Phase 1、Phase 3 |
| LLM 推理 | `#E8A838` (琥珀) | 智能、创新 | Phase 2、Phase 5、LLM Service |
| Trace 分析 | `#7B68EE` (淡紫) | 深度、洞察 | Phase 4 |
| 配置生成 | `#CD5C5C` (砖红) | 执行、输出 | Phase 6、ChaosBlade |
| 编排控制 | `#708090` (板岩灰) | 中性、控制 | Orchestrator、数据流箭头 |

#### 3.1.2 风险等级色彩

| 风险等级 | 色彩 (HEX) | 透明度 |
|----------|------------|--------|
| CRITICAL | `#DC143C` (深红) | 100% |
| HIGH | `#FF6347` (番茄红) | 85% |
| MEDIUM | `#FFA500` (橙色) | 70% |
| LOW | `#90EE90` (浅绿) | 60% |

### 3.2 几何语义系统

#### 3.2.1 节点形状规范

| 形状 | 语义 | 应用场景 | 尺寸规范 |
|------|------|----------|----------|
| 圆角矩形 | 服务/组件 | Pipeline 阶段、核心服务 | 120×60 px |
| 圆柱体 | 数据存储 | 数据库、缓存、结果对象 | 80×50 px |

| 六边形 | 算法模块 | RiskRank 算法 | 80×70 px |
| 文档形状 | 输出产物 | PipelineResult、Config | 90×50 px |

#### 3.2.2 连接线规范

| 线型 | 语义 | 线宽 |
|------|------|------|
| 实线箭头 | 数据流 | 2px |
| 虚线箭头 | 控制流/可选路径 | 1.5px |
| 粗实线 | 主路径强调 | 3px |
| 双向箭头 | 双向通信 | 2px |

## 4. 空间布局与坐标定位

### 4.1 画布规格

| 属性 | 规格 |
|------|------|
| 画布尺寸 | 1200 × 800 px (3:2 比例) |
| 边距 | 上下左右各 40px |
| 有效绘图区 | 1120 × 720 px |
| 坐标系统 | 归一化坐标 [0.0, 1.0] |

### 4.2 分区规划

采用**九宫格 + 时间轴**混合布局：

```
┌───────────────────────────────────────────────────────────────────────┐
│  [0.0, 0.0]                                              [1.0, 0.0]   │
│ ┌─────────────┬─────────────────────────────────────┬───────────────┐ │
│ │             │                                     │               │ │
│ │   输入区     │           主体处理区                 │    输出区     │ │

│ │             │                                     │               │ │

│  [0.0, 1.0]                                              [1.0, 1.0]   │
```

| 规则类型 | 规范 |
|----------|------|
| 阶段水平间距 | 画布宽度的 13% (约 156px) |
| 阶段垂直间距 | 画布高度的 30% (约 216px) |
| 组件内边距 | 8px |
| 箭头与节点间距 | 10px |
| 标签与节点间距 | 5px (上方或下方) |

### 4.5 视觉层次

| 层次 | Z-Index | 包含元素 |
|------|---------|----------|
| 背景层 | 0 | 分区色块、网格参考线（仅设计时可见） |
| 连接层 | 1 | 数据流箭头、控制流虚线 |
| 节点层 | 2 | 所有组件节点 |
| 标注层 | 3 | 文字标签、图例 |
| 强调层 | 4 | 创新点高亮框、关键路径加粗 |

### 4.6 响应式适配

| 目标媒介 | 缩放策略 |
|----------|----------|
| 论文印刷 (单栏) | 缩放至 85mm 宽，保持比例 |
| 论文印刷 (双栏) | 缩放至 180mm 宽，保持比例 |
| 幻灯片展示 | 保持原始尺寸或放大至 1920×1280 |
| 在线文档 | SVG 格式，支持无损缩放 |
