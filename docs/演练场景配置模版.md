## 参数来源分类
### 一、固定值（直接写死）
| 字段路径 | 固定值 | 说明 |
| --- | --- | --- |
| `namespace` | `"default"` | 实验命名空间 |
| `Lang` | `"zh"` | 语言 |
| `Namespace` | `"default"` | 同上 |
| `definition.runMode` | `"SEQUENCE"` | 顺序执行 |
| `flowGroups[].scopeType` | `2` | 容器级别 |
| `flowGroups[].osType` | `0` | Linux |
| `flowGroups[].appType` | `1` | K8s应用 |
| `flowGroups[].displayIndex` | `1` | UI显示顺序 |
| `hosts[].k8s` | `true` | K8s环境 |
| `hosts[].scopeType` | `2` | 容器级别 |
| `hosts[].deviceType` | `0` | 容器设备 |
| `hosts[].osType` | `0` | Linux |
| `hosts[].allow` | `true` | 允许执行 |
| `hosts[].appScope` | `true` | 应用范围 |
| `hosts[].invalid` | `false` | 有效 |
| `hosts[].master` | `false` | 非主节点 |
| `hosts[].type` | `"host"` | 主机类型 |
| `attack[].stage` | `"attack"` | 攻击阶段 |
| `attack[].phase` | `2` | 攻击阶段码 |
| `attack[].nodeType` | `-1` | 默认节点类型 |
| `attack[].required` | `true` | 必须执行 |
| `attack[].sync` | `false` | 异步 |
| `attack[].user_check` | `true` | 用户确认 |
| `attack[].deletable` | `false` | 不可删除 |
| `attack[].failedTolerance` | `0` | 不容忍失败 |
| `attack[].interruptedIfFailed` | `false` | 失败不中断 |
| `attack[].argsValid` | `true` | 参数有效 |
| `recover[].stage` | `"recover"` | 恢复阶段 |
| `recover[].phase` | `8` | 恢复阶段码 |
| `recover[].order` | `2147483646` | 执行顺序 |
| `recover[].arguments` | `[]` | 空 |
| `recover[].args` | `[]` | 空 |
| `check` | `[]` | 空 |
| `prepare` | `[]` | 空 |


---

### 二、大模型生成
| 占位符 | 说明 | 示例 |
| --- | --- | --- |
| `{{EXPERIMENT_NAME}}` | 实验名称 | `"ts-travel-service-CPU压力测试"` |
| `{{EXPERIMENT_DESC}}` | 实验描述 | `"验证服务在CPU资源耗尽时的表现"` |
| `{{DURATION}}` | 实验时长（秒） | `300` |
| `{{FAULT_NAME}}` | 故障名称 | `"容器内Cpu满载"` |
| `{{FAULT_CODE}}` | 故障类型编码 | `"chaos.container-cpu.fullload"` |
| `{{FAULT_ARGUMENTS}}` | 故障参数（完整JSON） | 见下方参数模板 |


---

### 三、初始输入参数
| 占位符 | 说明 | 来源 |
| --- | --- | --- |
| `{{APP_NAME}}` | 服务/应用名称 | 用户指定或风险分析结果 |
| `{{KUBE_NAMESPACE}}` | K8s命名空间 | 用户指定，如 `"train-ticket"` |


---

### 四、接口获取
| 占位符 | 接口 | 请求参数 | 响应字段 |
| --- | --- | --- | --- |
| `{{APP_ID}}` | `GetUserApplications` | `key={{APP_NAME}}` | `appId` |
| `{{GROUP_NAME}}` | `GetUserApplicationGroups` | `appId={{APP_ID}}` | `groupName` |
| `{{APP_GROUP}}` | `GetUserApplicationGroups` | `appId={{APP_ID}}` | `appGroup` |


---

### 五、接口获取（hosts 信息）
调用 `GetScopesByApplication` 接口获取，请求参数：`appId={{APP_ID}}`

| 占位符 | 响应字段 | 说明 |
| --- | --- | --- |
| `{{APP_CONFIGURATION_ID}}` | `appConfigurationId` | 应用配置ID |
| `{{POD_NAME}}` | `deviceName` | Pod 全名 |
| `{{DEVICE_ID}}` | `deviceId` | 设备ID |
| `{{DEVICE_CONFIGURATION_ID}}` | `deviceConfigurationId` | 设备配置ID |
| `{{POD_IP}}` | `ip` | Pod IP |
| `{{CLUSTER_NAME}}` | `clusterName` | 集群名称 |
| `{{CLUSTER_ID}}` | `clusterId` | 集群ID |
| `{{NODE_GROUP}}` | `nodeGroup` | 节点分组 |
| `{{PORT}}` | `port` | Agent端口 |
| `{{VPC_ID}}` | `vpcId` | VPC ID |


---

### 六、自动生成（UUID）
| 占位符 | 说明 | 生成方式 |
| --- | --- | --- |
| `{{FLOW_ID}}` | 流程ID | `UUID.randomUUID()` |
| `{{ATTACK_ID}}` | 攻击节点ID | `UUID.randomUUID()` |
| `{{RECOVER_ID}}` | 恢复节点ID | `UUID.randomUUID()` |


---

### 七、拼接/计算
| 占位符 | 规则 | 示例 |
| --- | --- | --- |
| `recover.app_code` | `{{FAULT_CODE}} + ".stop"` | `"chaos.container-cpu.fullload.stop"` |
| `recover.activityName` | `"恢复(" + {{FAULT_NAME}} + ")"` | `"恢复(容器内Cpu满载)"` |
