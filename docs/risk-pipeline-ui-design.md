### 2.2 交互说明

| 元素 | 交互行为 |
|------|----------|
| 命名空间下拉框 | 从K8s获取可用namespace列表 |
| 开始分析按钮 | 调用 `/pipeline/{namespace}` 启动分析，按钮变为"分析中..." |
| 进度条 | 根据 `progressPercent` 实时更新 |
| 阶段状态卡片 | 点击可查看详细信息，失败阶段显示红色 |
| 执行日志 | 可折叠/展开，支持搜索和滚动 |

### 2.3 状态变化

```
初始状态          →  执行中           →  完成/失败
┌────────────┐    ┌────────────┐    ┌────────────┐
│ 🚀 开始分析 │ →  │ 🔄 分析中... │ →  │ ✅ 查看结果 │
└────────────┘    └────────────┘    └────────────┘
                                    ┌────────────┐
                                 or │ ❌ 重新分析 │
                                    └────────────┘
```

### 3.2 组件说明

| 组件 | 数据来源 | 交互 |
|------|----------|------|
| 执行摘要卡片 | `result.summary` | 无交互，纯展示 |
| 服务风险排名表 | `result.phase3Result.rankedServices` | 点击行跳转服务详情 |
| 服务拓扑图 | `ServiceMap` + 风险着色 | 支持缩放、拖拽、点击节点 |
| 故障场景列表 | `result.phase5Result.chaosScenarios` | 点击查看详情或执行 |
